# Minecraft 1.20.1 Forge ↔ San Andreas DE: диагностический прототип

**Это исходники первого теста связи, не готовый мод совмещения миров.**
Облачная проверка охватывает Java-ядро и JavaScript с имитацией API CLEO.
Forge-адаптер не собран здесь: загрузка Maven Forge заблокирована облачным
прокси. CLEO/Win32 и обе установленные игры здесь недоступны. Портал, блоки
в GTA, общий инвентарь, TNT по машинам и поршни пока не реализованы.

Подготовлено для SA DE exe **1.0.113.21181**, CLEO Redux **1.5.1 x64**,
Minecraft Java **1.20.1**, Forge **47.x**. Кандидат сборки — **47.2.0**;
для первого опыта используйте отдельный чистый профиль с этой версией,
не меняя существующую сборку модов. Поддержка CLEO для указанного exe заявлена
в официальной документации в колонке Steam; точный магазин ещё нужно сверить.
Пользователь уточнил источник установки: «торрент». Это не подтверждает
идентичность exe Steam-сборке; для этой копии совместимость пока неизвестна.

Исследование: [FEASIBILITY.md](docs/FEASIBILITY.md).
Протокол: [CONTRACT.md](docs/CONTRACT.md).
Фактические действия и результаты: [MODLOG.md](MODLOG.md).

## Что делает первый тест

Два небольших файла в `C:\UMBridge\sa-de-v1` передают heartbeat, session,
порядковый номер, ACK и необязательные координаты. Каждый процесс пишет только
свой файл. Minecraft читает состояние на клиентском потоке, а файловый обмен
выполняет отдельный worker примерно два раза в секунду. CLEO делает короткую
INI-операцию каждые 500 мс. Никаких сетевых портов, телепортов, взрывов, изменения
мира, фокуса окна, registry, памяти игры и установки нового загрузчика.

`roundtrip` означает, что свежий пакет другой стороны подтвердил получение
нашего пакета. Это доказательство связи скриптов, а не общего игрового мира.
Старый файл не считается живым процессом: неизменный seq истекает за 3 секунды.

## Windows: подготовка

**Самый простой запуск сборки:** полностью распакуйте ZIP ветки репозитория,
затем откройте двойным щелчком `BUILD.bat` в корне репозитория. Текущая папка
терминала значения не имеет. Используется установленный JDK:
`C:\Program Files\Eclipse Adoptium\jdk-17.0.20.101-hotspot`.

`JAVA_HOME` и `PATH` задаются через `setlocal` только для процесса сборки.
Запуск PowerShell с `-ExecutionPolicy Bypass` относится только к дочернему
процессу; настройки Windows и постоянная execution policy не меняются.
Потребуется интернет для Gradle/Forge/Minecraft-зависимостей.

Журнал каждого запуска сохраняется в корневой `BUILD-LOGS\build-<дата-время>.log`.
При ошибке окно остаётся открытым, выводит причину и путь к журналу. После
успешного `clean build` в корне создаётся и открывается в Проводнике `READY`:
jar, `umsa-bridge[fs].js`, `INSTALL-RU.txt`, `SHA256SUMS.txt` и копия журнала.
Существующая папка READY сохраняется как `READY.previous-<дата-время>` перед
попыткой сборки: старый jar не будет выдан за результат неудачного нового запуска.
Старые журналы и папки previous автоматически не удаляются.

READY с jar появляется только после успешной сборки на вашем ПК. ZIP ветки
содержит исходники; сборка в облаке по-прежнему не завершена из-за запрета
доступа к Maven Forge. Успех компиляции отдельно не доказывает работу в играх.
Ничего в игровые папки автоматически не копируется. Следующие шаги описывают
резервное копирование и ручную установку после успешной сборки.

Нужны собственные легальные установки обеих игр, уже работающий CLEO Redux
1.5.1 x64 с **IniFiles** и полный **JDK 17** для сборки. Java runtime из лаунчера
может не содержать javac. Minecraft запускается через обычный авторизованный
лаунчер; dev-run не заменяет проверку конечного jar.

1. Закройте игры. Через `um scan "<папка игры>"` на своём ПК проверьте найденные
   пути сохранений; облако их не знает. Сделайте отдельные резервные копии
   сохранений, конфигураций и рабочего CLEO. Из корня Universal Modder:

   ```powershell
   .\bin\um.cmd backup create "<проверенный путь сохранений SA DE>" --name sa-de-before-bridge
   .\bin\um.cmd backup create "<проверенный путь профиля Minecraft>" --name mc-before-bridge
   ```

   Замените placeholders существующими путями. Создайте отдельный gameDir
   Minecraft и новый тестовый мир. В GTA используйте отдельное сохранение
   свободной игры. Не испытывайте будущие взрывы в основном сохранении.

2. Запишите из свойств **реального запускаемого SanAndreas.exe** версию и магазин.
   Для однозначной идентификации, без передачи exe:

   ```powershell
   $exe = '<полный путь к SanAndreas.exe>'
   (Get-Item -LiteralPath $exe).VersionInfo | Select-Object FileVersion, ProductVersion
   Get-FileHash -LiteralPath $exe -Algorithm SHA256
   ```

3. Создайте только каталог mailbox. Если каталог уже занят другим экспериментом,
   выберите новый короткий абсолютный путь и одинаково задайте его в ROOT скрипта
   CLEO и JVM-параметре `-Dumsa.dir=...`. Не смешивайте два экземпляра игр.

   ```powershell
   New-Item -ItemType Directory -Force 'C:\UMBridge\sa-de-v1'
   ```

   Не используйте OneDrive/сетевой диск. В IniFiles 128-байтный буфер, поэтому
   путь и пакеты должны оставаться короткими. Сам скрипт каталог не создаёт.

## Windows: сборка кандидата Forge

Из `examples\minecraft-sa-de-bridge` в PowerShell:

```powershell
$env:JAVA_HOME = '<папка установленного JDK 17>'
.\tools\Build-Forge.ps1
if ($LASTEXITCODE -ne 0) { throw 'Build failed; do not install a jar from an older run' }
```

Скрипт загружает Gradle 8.1.1 с официального сайта, проверяет официальный
SHA-256 и запускает ForgeGradle 6.0.24 для Forge 1.20.1-47.2.0. Ничего в игры
не копирует. Не ослабляйте TLS/checksum и не подменяйте ошибку сборки заглушками.
Если локальная политика запрещает PowerShell-скрипты, соблюдайте её; не требуется
глобально менять execution policy. С уже установленными JDK17 и Gradle 8.1.1
эквивалентная команда из этой папки: `gradle --no-daemon -p mc build`.

При успешной сборке появится
`mc\build\libs\um-sa-bridge-0.1.0-diagnostic.jar`.
Сохраните полный build log и SHA-256 jar. Результат сборки в Windows ещё не
подтверждён; ошибка API здесь — основание исправить адаптер, а не игнорировать её.

## Windows: этап A — связь в реальных играх

Пользователь выполняет ручное копирование после просмотра исходников:

1. С закрытым Minecraft скопируйте **только успешно собранный** jar в `mods`
   отдельного профиля Forge 1.20.1-47.2.0. Запустите профиль, откройте новый
   одиночный мир. Проверьте появление мода в списке и `[UMSA]` в `logs\latest.log`.
   Если GTA не запущена, ожидается `state=waiting`, либо `stale` от старого файла.
2. С закрытой GTA скопируйте только `cleo\umsa-bridge[fs].js` в **фактический**
   рабочий каталог CLEO, указанный существующим `cleo_redux.log`. Обычно он
   рядом с `Gameface\Binaries\Win64\SanAndreas.exe`, но CLEO может использовать
   fallback в AppData. Не копируйте второй экземпляр в другой каталог.
   Не заменяйте ASI loader, `cleo_redux.asi`, другие скрипты или плагины.
3. Оставьте `READ_CJ = false`. Суффикс `[fs]` обязателен для IniFiles при обычной
   политике Lax. В Strict проверьте разрешение fs в `cleo.ini`; не включайте
   глобальное разрешение всех небезопасных операций. При запрете прав остановитесь
   и решите его в рамках собственной политики. В журнале должен быть IniFiles
   plugin x64; загрузка других плагинов не заменяет его.
4. Вручную запустите GTA и загрузите тестовое сохранение. Следите за журналами
   в двух окнах PowerShell (пути замените фактическими):

   ```powershell
   Get-Content -LiteralPath '<профиль MC>\logs\latest.log' -Tail 40 -Wait
   # Во втором окне:
   Get-Content -LiteralPath '<рабочий путь CLEO>\cleo_redux.log' -Tail 40 -Wait
   ```

5. В течение примерно 10 секунд активного выполнения оба журнала должны показать
   `[UMSA] state=roundtrip`, разные ненулевые session, увеличивающиеся sent/seq
   и ACK на session другой стороны. В этот момент журнал GTA должен показать
   координаты MC с `playing=1`. Обратное `playing=0` ожидаемо: чтение CJ выключено.
   `peer-seen` без `roundtrip` означает только одностороннюю связь.
6. Вручную закройте GTA. Если Minecraft продолжает выполнять тики/worker, его
   состояние должно стать `stale` примерно через 3–5 секунд. Старый `gta.ini`
   оставьте на месте: тест проверяет, что он не считается живым. Снова запустите
   GTA, загрузите сохранение: новая session, затем новый `roundtrip`.
7. Повторите в обратном направлении: выход из Minecraft, `stale` в активно
   выполняющемся CLEO; запуск MC → новая session → `roundtrip`. Если GTA
   при потере фокуса приостанавливает скрипты, stale наблюдайте после возвращения
   к игре; отсутствие выполнения скрипта не является сетевой ошибкой.

Пауза/меню не доказывают остановку мира: heartbeat может продолжаться независимо
от симуляции. Не минимизируйте окна при первом тесте. Не держите mailbox-файлы
открытыми через `Get-Content -Wait`: постоянный handle может мешать atomic rename.
Для разового просмотра используйте обычный `Get-Content`.

## Windows: этап B — read-only координаты CJ

Только после успешного этапа A: закройте GTA, в скопированном скрипте поменяйте
`const READ_CJ = false` на `true`, затем запустите тестовое сохранение.
Используются только `new Player(0)`, `isPlaying()`, `getChar().getCoordinates()`;
их имена сверены с SA Unreal definitions, работа на вашем exe ещё не проверена.

Пройдите CJ несколько шагов без транспорта/миссии. В Minecraft-журнале поле
peer теперь должно иметь `playing=1` и изменяющиеся qx/qy/qz. Затем пройдите
персонажем Minecraft: в CLEO-журнале меняется его peer. q — координата ×10,
оси ещё не преобразованы. Не ожидайте совпадения местоположения персонажей.
При ошибке команды верните READ_CJ=false с закрытой GTA и сохраните полный
текст ошибки. Это ограничение API/совместимости, а не доказательство невозможности
всего проекта.

## Критерий успеха и что прислать для продолжения

Успех этого шага: `roundtrip` **в обоих настоящих игровых журналах**, координаты
MC доходят до CLEO, после B координаты CJ доходят до MC; выход/перезапуск одной
игры приводит к stale/новой session без игрового воздействия. Синтетические
журналы ниже не являются этим доказательством.

Для следующего шага достаточно текстом: магазин, точные версии exe/Forge/CLEO,
SHA-256 jar и exe, фрагменты `[UMSA]` с обеих сторон (включая запуск, roundtrip,
stale, reconnect), первая полная ошибка при её наличии. При неизвестном методе
нужны соответствующие строки из сгенерированного `CLEO\.config\*.d.ts` и версия
definitions. Не нужны ключи, полный exe, игровые архивы или сохранения.
Логи CLEO перезаписываются при запуске — сохраняйте копию до следующего теста.

## Если связь не появилась

| Наблюдение | Следующая проверка |
|---|---|
| Нет `[UMSA]` в MC | Jar действительно собран сейчас, правильный профиль/Forge, mod list и первая ошибка загрузки |
| Нет `[UMSA]` в CLEO | Фактический CLEO path, HOST=sa_unreal, загрузка сохранения, один экземпляр скрипта |
| `IniFile` не определён | x64 IniFiles и compound definitions unknown_x64, существующий журнал загрузчика |
| WriteString/permission ошибка | Каталог существует, доступен пользователю, `[fs]` сохранён, Strict/fs policy |
| `peer-seen`/waiting на одной стороне | Одинаковый абсолютный путь, обе игры пишут свои файлы, формат [bridge]/packet, меняющиеся seq |
| I/O/sharing error Java | Уберите открытые редакторы/долгие handles mailbox, проверьте локальный диск; не заменяйте atomic write частичным |
| Файлы меняются, CLEO видит старое | Возможное кэширование Win32 profile API: сохранить оба файла/логи и остановить тест; Node этого не проверяет |
| Краш/ошибка после READ_CJ=true | Вернуть false, оставить протокол, сохранить ошибку и локальные definitions; никаких случайных offsets |

После трёх одинаковых неудач не повторяйте запуск без нового диагноза.

## Откат

Закройте обе игры. Уберите только добавленные `umsa-bridge[fs].js` и jar из
тестового профиля. Не удаляйте загрузчик или IniFiles: они существовали раньше.
Mailbox-каталог и логи можно оставить для диагностики; bridge не трогает saves.
Не запускайте install/remove скрипты из примера GTA V для этой игры.

## Повторяемая облачная проверка

Нужны Python 3.10+, Node и **полный JDK17 или новее с поддержкой --release 17**:

```bash
python3 tools/check-local.py
```

Проверяется реальное Java-ядро, реальные исходники CLEO-скрипта с имитацией
IniFile/Player/wait, обмен между разными процессами, ACK, телеметрия, restart,
stale и некорректные пакеты. Сам Forge-класс в эту компиляцию не включается.
Это прямо указано в выводе; нет заглушек Forge, выдаваемых за успешную сборку.

Написано Codex; сторонние игровые ресурсы и бинарники загрузчиков не включены.
Кредиты: CLEO Redux / IniFiles (cleolibrary), Sanny Builder Library,
MinecraftForge; архитектурный разбор Universal Modder GTA V passthrough.
